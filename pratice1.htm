JAVA
Java is a high-level, object-oriented programming language used to develop web, desktop, and mobile application. It is platform-independent because java code runs on the JVM

HTML (HyperText Markup Language)
HTML is the standard markup language used to create the structure of web pages. It uses tags like to display content on the browser

CSS (Cascading Style Sheets)
CSS is used to style and web pages. It controls colors,fonts, layout, spacing, and responsiveness, making websites look attractive

JavaScript
JavaScript is a scripting language used to make web pages interactive and dynamic. It is used for actions like form validation, animations, and updating content without reloading the page

Servlet
A Servlet is a Java-based server-side technology used to handle client request and generate dynamic web content. It runs on a web server like Tomcat and is mainly used in web appliations.

JDBC (Java Database Connectivity)
JDBC is an API in java used to connect and interact with databases.It allows java program to execute SQL queries, retrieve data, and update records.

Spring
Spring is a Java framework used to build enterprise-level application. It simplifies development by providing features like dependency injection, security, and web.

React
React is a Javascript library used interface (UI), espically for single-page application. It uses components and makes web apps fast and efficient.
